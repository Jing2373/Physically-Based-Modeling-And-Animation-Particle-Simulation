#  Particle Simulation

A 3D particle physics simulation implemented in C++ with OpenGL.

Particles are affected by gravity and bounce inside a cubic boundary.
The simulation uses the Forward Euler method for numerical integration.

## Features

- Gravity simulation
- Boundary collision and bouncing
- Dynamic particle emission
- OpenGL visualization
- Forward Euler integration

## Controls

- `G` / `g`: Adjust gravity
- `C` / `c`: Adjust restitution
- `E` / `e`: Emit particles

## Academic Context

This project was developed as part of a physics-based modeling and animation course assignment.
